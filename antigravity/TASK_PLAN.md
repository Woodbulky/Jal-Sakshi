# Antigravity Task Plan

## 1. Bootstrap

Create the Next.js TypeScript frontend with Tailwind, shadcn/ui, Framer Motion, MapLibre, and charting.

## 2. Landing page

Create the JAL-SAKSHI landing page with a clear Get Started action.

## 3. Service-area selector

Create State → District → Block → Village/Service Area flow. Use Vitpur only as the fictional demo service area.

## 4. Dashboard shell

Create header, navigation, network map, health panel, active incidents, agent activity, and work-order/SLA areas.

## 5. Map

Build `WaterNetworkMap.tsx` using backend asset and connection data.

## 6. Telemetry UI

Build reusable flow, pressure, level, energy, and water-quality cards/charts.

## 7. Agent UI

Build streaming agent activity and state indicators.

## 8. Incident/work-order UI

Build incident cards, incident drawer, work-order panel, SLA clock, and escalation timeline.

## 9. Demo controls

Build `FaultInjectionPanel` calling the backend simulation endpoint.

## 10. Verification UI

Build RESTORATION_DETECTED → VERIFYING → VERIFIED/REOPENED states.

## 11. Asset health

Build failures, MTTR, recent incidents, risk, and recommendation cards.

## 12. Polish

Responsive layout, loading/error states, accessibility, reduced-motion behavior, smooth transitions, and final visual consistency.
